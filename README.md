# Restricciones de parqueo El Dorado

Diagrama interactivo de las restricciones entre posiciones de parqueo del Aeropuerto El Dorado, expresadas en subcategorías AMS (B, C1–C6, D1–D2, E1–E4, F1–F2).

- Pestañas por zona: Espigón Sur, Espigón Norte, Internacional, Remotas, T2, Carga y MRO.
- Flechas de condición (Si) a efecto (Entonces) entre posiciones.
- Buscador por tipo IATA o subcategoría.
- Tarjetas con los tipos IATA de cada subcategoría.

Es un solo archivo HTML estático, sin dependencias ni claves. Abre `index.html` en el navegador.

Fuente: Plan Operativo Aeropuerto Internacional El Dorado (Tabla 2.8) y tabla de grupos AMS.
